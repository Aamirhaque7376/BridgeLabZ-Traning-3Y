## How to run
1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run one file at a time, for example:

   `node Q1_Async_Coffee_Maker.js`

For Q6, use Node.js 18 or newer (global `fetch` is required), or run it in a modern browser console. The optional HTML card rendering runs only when a browser page contains an element with `id="product-container"`.

Random failures are intentional in the questions that request failure simulation. Run those files again if a simulated failure occurs.

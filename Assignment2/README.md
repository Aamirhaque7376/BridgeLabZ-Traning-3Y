## Run the programs

Open a terminal in this folder and run any file with Node.js, for example:

```bash
node Q1_Scope_Conflict_Resolver.js
```

You can also open a `.js` file and paste its code into the browser developer console.

Each question is in a separate JavaScript file and uses core JavaScript only.

# Assignment 4 — JavaScript (ES6+)

This folder contains all 9 completed tasks. Each task has its own HTML and JavaScript file.

## How to run
1. Extract the `Assignment4.zip` file.
2. Open the `Assignment4` folder in VS Code.
3. Open any task HTML file in a browser (recommended: use the VS Code Live Server extension), or double-click the HTML file.
4. JavaScript output and validation messages are shown on the page. Open browser DevTools → Console to see console output where applicable.

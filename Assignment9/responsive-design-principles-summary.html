Responsive Design Principles

Fluid Layouts

Layouts use flexible widths so content can adapt to available space.

width: 100%;
max-width: 1200px;

Flexible Media

Images and videos should shrink within their containers.

img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Media queries apply different rules at useful screen sizes.

@media (max-width: 600px) {
    ...
}

# Assignment 5 - HTML & CSS Solutions

This folder contains 10 separate questions. Each question has its own folder with:
- index.html
- style.css

No JavaScript or external CSS frameworks are used.

## How to run
1. Open any Q1...Q10 folder.
2. Open `index.html` in a browser.
3. Keep `style.css` in the same folder so the stylesheet loads correctly.

Note: Some examples use image URLs from Unsplash for visual demonstration.

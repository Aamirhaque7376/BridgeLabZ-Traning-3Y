# DOM

This folder contains 9 independent DOM practice projects. Every project has its own `index.html`, `style.css`, and `script.js` files.

## Projects
1. Dynamic Product List Manager (event delegation and inline editing)
2. Live Character Counter (100-character limit and `preventDefault()`)
3. Multi-Step Form (Next/Back and validation)
4. Theme Switcher (`setAttribute()` and `data-theme`)
5. Image Gallery Modal (`stopPropagation()`)
6. Real-Time Student Table Filter
7. Mouse Coordinates and Double-Click Red Dot
8. Custom Dropdown (document click listener in capture phase)
9. Form Submit Blocker (live validation and `preventDefault()`)

## How to run in VS Code
1. Extract `DOM.zip`.
2. Open the `DOM` folder in VS Code.
3. Open any project folder, for example `Q1_Product_List_Manager`.
4. Open its `index.html` in a browser. You can use the VS Code Live Server extension, or double-click `index.html`.
5. Each project loads its own `style.css` and `script.js`; no frameworks or libraries are used.

The gallery uses remote Picsum image URLs, so an internet connection is needed to load those six sample images.

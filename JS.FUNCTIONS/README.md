# JS.FUNCTIONS

JavaScript ES6+ practice assignment containing nine separate questions.

## Files

- `Q1_Callback.js` — callback functions
- `Q2_ApplyOperation.js` — callbacks with array operations
- `Q3_ArrowFunctionThis.js` — arrow function `this` vs normal function `this`
- `Q4_CarPrototype.js` — constructor functions and prototype methods
- `Q5_PersonStudentPrototype.js` — inheritance using prototypes
- `Q6_PersonFacultyProfessor.js` — multi-level prototype chain
- `Q7_ClosureMultiplier.js` — closures
- `Q8_CustomMyMap.js` — custom `Array.prototype.myMap()`
- `Q9_PrototypeAndClassInheritance.js` — prototype inheritance and ES6 classes

## How to run

1. Open this folder in VS Code.
2. Open a terminal in the folder.
3. Run one file at a time using Node.js:

```bash
node Q1_Callback.js
```

Replace `Q1_Callback.js` with the file you want to execute, for example:

```bash
node Q9_PrototypeAndClassInheritance.js
```

No external libraries or frameworks are required.

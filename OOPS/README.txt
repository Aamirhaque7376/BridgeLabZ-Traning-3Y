How to run:
1. Install Node.js if it is not already installed.
2. Open this OOPS folder in VS Code.
3. Open the terminal.
4. Run one file at a time, for example:
   node Q1_Student_Result_Processing.js

Repeat with the other file names.

Notes:
- Q1 grade ranges used: A = 90+, B = 75-89.99, C = 50-74.99, F = below 50.
- Q5 fare formula used: Rs. 30 base fare + Rs. 12 per kilometre.
- Q6 low stock means fewer than 5 units; inventory value = price multiplied by stock.
- Each question is in a separate JavaScript file as requested.

# Assignment 10 — Bootstrap

Each question has its own folder with a separate `index.html` and `style.css`, built with Bootstrap 5 via CDN.

| Folder | Question |
|---|---|
| q1-company-landing | Company Landing Page |
| q2-portfolio | Personal Portfolio Basics |
| q3-product-catalog | Product Catalog (Grid System) |
| q4-restaurant-menu | Restaurant Menu Page |
| q5-blog-theme | Custom Themed Blog Homepage |
| q6-notifications-dashboard | Notifications Dashboard |
| q7-task-tracker | Task Tracker with Badges |
| q8-pricing-plans | Pricing Plans |
| q9-blog-pagination | Blog Pagination & Pager |
| q10-travel-carousel | Travel Agency Showcase (Carousel & Progress Bar) |

Just open any `index.html` file directly in a browser — everything loads from the Bootstrap CDN, no build step needed.
